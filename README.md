## Run locally
Open `index.html` in a browser, or serve the `crypto` directory with any static web server.

## Important notes
- The site is a static front-end. The login page is intentionally a demo and does not authenticate users.
- Before publishing, replace demo team profiles with real information and review all content/branding.
- Cryptocurrency is risky; this site does not provide financial advice.
- Google Fonts are loaded externally. The rest of the website assets are included in this folder.
